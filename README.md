## 🚀 Publicar una Release

1. Entra en [Crear una Release](https://github.com/mejai84/GameActions-Videos/releases/new).
2. Usa el tag `v2026.11.23` (créalo allí si no existe).
3. Título sugerido: `GameActions – GTA 6 (ediciones)`.
4. Adjunta los MP4, miniaturas y metadatos desde tu equipo.
5. Verifica los archivos antes de pulsar **Publish release**.

Consulta [la plantilla de publicación](releases/PLANTILLA_RELEASE.md).

## 🔒 Privacidad, derechos y copias

- Se recomienda **Private** hasta verificar los derechos para almacenar y distribuir el contenido.
- Las ediciones de videos de terceros requieren autorización para su distribución. Incluir créditos no equivale a obtener permiso.
- No agregues MP4 ni archivos de producción grandes al código fuente.
- Una Release no reemplaza copias de seguridad independientes.
